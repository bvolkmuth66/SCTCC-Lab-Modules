Module 5 Knowledge Checker: IPv4 Access Control Lists

This ungraded formative activity verifies your conceptual understanding of access control list evaluation order, wildcard mask calculation, list placement, and verification before you attempt the Packet Tracer activities. Answer all ten questions and select Submit Assessment. Return to the module page and launch the Command Syntax Checker once you have achieved a score of ten out of ten.

1. What is the primary operational purpose of an IPv4 access control list in a routed enterprise network?

2. A packet matches the deny statement on line 10 of an access control list. What does the router do next?

3. An administrator configures an access control list containing only deny statements and applies it to an interface. What is the operational result?

4. Which wildcard mask matches every host address on a network that uses the subnet mask 255.255.255.0?

5. What does a binary zero in a wildcard mask instruct the router to do?

6. Why must a standard access control list be placed as close to the destination as possible?

7. An administrator must deny Telnet traffic from the Student segment to one server while permitting web traffic from that same segment to that same server. Which list type satisfies this policy?

8. Which command applies an access control list to traffic arriving on an interface, before the router performs the routing table lookup?

9. Which command restricts the source addresses permitted to open a remote management session to the virtual terminal lines?

10. During a connectivity test the match counter on every entry of an applied access control list remains at zero. What does this evidence indicate?
