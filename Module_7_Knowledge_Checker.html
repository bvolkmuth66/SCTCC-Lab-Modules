Module 7 Knowledge Checker: Wireless LAN Controllers

This ungraded formative activity verifies your conceptual understanding of wireless service sets, the split media access control architecture, the access point join process, interface mapping, and wireless security methods before you attempt the Packet Tracer activities. Answer all ten questions and select Submit Assessment. Return to the module page and launch the Command Syntax Checker once you have achieved a score of ten out of ten.

2. What distinguishes the basic service set identifier from the service set identifier?

3. Under the split media access control model, which function remains on the access point rather than moving to the controller?

4. A lightweight access point loses contact with its controller. What does it do?

5. Which port numbers does the tunnel between an access point and its controller use?

6. An access point is connected to a switch port in one wing of a building. Where does the client traffic it receives enter the wired network?

7. An access point is placed on a different segment from the controller management interface. No address option and no name service record have been configured. What is the result?

8. What does a dynamic interface on the controller accomplish?

9. An institution must be able to revoke wireless access for one departing employee without affecting anyone else. Which security method satisfies this requirement?
