1. What is the primary operational purpose of configuring an EtherChannel?

  • To dynamically route packets across multiple isolated virtual local area networks.
  • To combine multiple physical Ethernet links into a single logical high-bandwidth channel for increased throughput and redundancy.
  • To encrypt administrative command line traffic crossing a shared distribution switch.

2. Which protocol is an open-standard IEEE protocol used to dynamically negotiate EtherChannel aggregation?

  • Port Aggregation Protocol
  • Link Aggregation Control Protocol
  • Spanning Tree Protocol

3. Which command mode keyword initiates active Link Aggregation Control Protocol negotiation on a physical interface?

  • channel-group 1 mode active
  • channel-group 1 mode passive

4. Why must all physical interfaces assigned to a port channel share identical configuration parameters such as speed, duplex, and trunking mode?

  • To ensure the spanning tree root bridge election prioritizes the correct MAC address.
  • To prevent configuration mismatches that cause member ports to be suspended from the aggregation group.
  • To allow native untagged traffic to bypass the 802.1Q tag insertion process.

  • show vlan brief
