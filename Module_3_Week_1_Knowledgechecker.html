Module_3_Week_1_Knowledgechecker

1. What is the primary operational purpose of the Spanning Tree Protocol?

  • To dynamically route packets between isolated broadcast domains.
  • To prevent broadcast storms by blocking redundant physical paths.
  • To encrypt administrative command line traffic traversing the network.

2. Which command instructs the hardware to utilize the Rapid Spanning Tree Protocol?

  • spanning-tree mode rapid-pvst
  • switchport mode trunk
  • spanning-tree vlan 10 root primary

3. Why must administrators deploy Bridge Protocol Data Unit Guard on access ports?

  • To disable the physical interface if an unauthorized switch attempts to alter the logical topology.
  • To bypass the listening and learning states for faster endpoint device connectivity.
  • To automatically calculate the lowest physical MAC address for the root bridge election.

4. Which bridge priority value, combined with a manual assignment, ensures a switch forces itself to become the root bridge?

  • 32768
  • 65535
  • 4096

5. What is the explicit operational purpose of enabling PortFast on an access interface?

  • To bypass standard listening and learning port states and immediately transition to forwarding.
  • To allow untagged native traffic to cross an 802.1Q transit link safely.
  • To aggregate multiple physical interfaces into a single logical channel group.
