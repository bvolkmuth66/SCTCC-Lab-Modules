Topology and Policy Scenario

Two IOS XE routers, R1 at 192.168.12.1 and R2 at 192.168.12.2, share a management segment with an administrator's laptop. A local user named admin with password cisco and privilege level 15 already exists on both routers, and AAA login authentication and authorization are already configured.

The change request adds one time server to R1 only. R2 must not change. The laptop has a folder named C:\m13 containing a file named ntp.json that describes the new server. The resource that holds R1's time configuration is:

https://192.168.12.1/restconf/data/Cisco-IOS-XE-native:native/ntp

Requests and responses use JSON, so the header for both the Accept and Content-Type fields is:

application/yang-data+json

Enter each step in the order the work requires. Entries are not case sensitive, extra spaces are ignored, and quotation marks around a header are optional. curl options may be entered in any order.
