Module 12 Syntax Checker: Virtual Adapter Modes

This ungraded formative activity verifies that you can place a virtual machine on the network deliberately and prove where it ended up. Configuration steps are entered as hypervisor settings paths using the greater than symbol between levels; verification steps are entered as commands, inside the guest or at the switch. Work through all eleven stages to achieve a 100 percent verification score, then return to the module page.

The Setup

Your laptop is connected to pod switch S1 on FastEthernet0/6. The pod network is 192.168.10.0/24 and the pod router is 192.168.10.1. A workstation on the pod is at 192.168.10.25. A Linux virtual machine named VM1 is installed and currently powered off.

The task is to place VM1 on the pod network as a host in its own right, prove it from both sides of the boundary, then change it to address translation and observe precisely what changes.

Settings paths are not case sensitive and spacing around the greater than symbol is ignored.
