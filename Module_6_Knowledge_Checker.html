Module 6 Knowledge Checker: Network Address Translation

This ungraded formative activity verifies your conceptual understanding of the four address designations, interface direction, translation methods, and verification before you attempt the Packet Tracer activities. Answer all ten questions and select Submit Assessment. Return to the module page and launch the Command Syntax Checker once you have achieved a score of ten out of ten.

1. Why does a service provider router discard a packet that carries a private IPv4 address as its source?

2. An internal workstation is configured with the address 192.168.10.25. What is this address called in the translation table?

3. What do the local and global terms describe in the translation address designations?

4. An administrator completes a translation configuration, sends test traffic from an internal host, and finds the translation table completely empty. What should be investigated first?

5. Which translation method permits a connection to be initiated from the outside network toward an internal server?

6. A dynamic pool contains five public addresses and is not configured for overload. A sixth internal host sends traffic toward the internet. What happens?

7. How does a router performing Port Address Translation distinguish the conversations of many internal hosts that share one public address?

8. In the command ip nat inside source list 1 pool CAMPUS_POOL, what does a permit entry in access control list 1 cause the router to do?

9. A student pings the outside interface of the border router from an internal workstation. The ping succeeds but no translation entry appears. Why?

10. Why must dynamic entries be cleared before retesting an amended translation configuration?
